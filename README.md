# 🏦 Bank Account Management System

A console-based Bank Account Management System developed using Python and Object-Oriented Programming (OOP). This project simulates basic banking operations, including deposits, withdrawals, and balance management.

## ✨ Features

- 👤 Account holder details
- 💰 Opening balance management
- 📥 Deposit (credit) operations
- 📤 Withdrawal (debit) operations
- 🧮 Automatic final balance calculation
- 📊 Transaction details display
- ✅ Basic input validation
- ⚠️ Insufficient balance handling

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

## 📚 Concepts Practiced

- Classes and Objects
- Constructors (`__init__`)
- Instance Variables and Methods
- Conditional Statements
- User Input and Basic Validation
- F-Strings

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/hitesh1796/bank-account-management-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bank-account-management-system
   ```

3. Run the Python program:

   ```bash
   python bank_account.py
   ```
